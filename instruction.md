# How to connect

## Install once
1. **vJoy**: https://github.com/BrunnerInnovation/vJoy/releases
   Then open **Configure vJoy**, tick **Enable vJoy**, set **Buttons = 32**, and click **Apply**.
2. **Node.js**: https://nodejs.org/
3. **Telemetry plugin** (for speed and fuel on the phone): https://github.com/RenCloud/scs-sdk-plugin/releases/tag/V.1.12.1
   Copy `Win64\scs-telemetry.dll` into `Euro Truck Simulator 2\bin\win_x64\plugins\` (create the `plugins` folder if it doesn't exist).

## Every time you play
1. Double-click `companion\start-companion.bat` and keep its window open.
2. Plug the phone into the PC with USB.
3. Open the app. It should say **Connected**.
4. Start ETS2.

## Set up ETS2 once
In **Options → Controls**, choose **vJoy Device**, then set:
- **Steering**: turn the phone wheel
- **Throttle**: press ACC
- **Brake**: press BRAKE

In **Options → Keys & Buttons**, click an action, then press the same button on the phone (Horn, PASS, indicators, lights and so on).
